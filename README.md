# Quantium Retail Strategy & Analytics — Chip Category Review

This repo is Tushar's work from the **Quantium Virtual Internship** (hosted on Forage,
formerly "InsideSherpa"), *Retail Strategy and Analytics* track. The brief: a fictional
retailer's Category Manager, **Julia**, wants to understand who buys chips, how they buy
them, and where there's an opportunity to grow the category — using a year of transaction
data plus customer segment data (life stage + spending tier).

The repo had 26 files sitting flat in the root with no folders, mixing raw data, code,
generated charts, Forage's own task briefs, and Tushar's final deliverables together —
hard for anyone (including future-Tushar) to tell what's *his work* vs. *reference
material*, or what order things run in. This README and the folder layout below fix that.

## The pipeline, step by step

Everything in `outputs/` and `data/processed/` is *generated* — never edit those files by
hand, just re-run the scripts.

| Step | Script | Reads | Writes | What it does |
|---|---|---|---|---|
| 1 | `01_data_cleaning.py` | `data/raw/*` | `data/processed/*_clean.csv` | Converts Excel date serials to real dates, drops exact duplicate rows, extracts `PACK_SIZE` and `BRAND` from the product name text, fixes inconsistent brand spellings (e.g. "RRD" → "Red Rock Deli"), removes salsa *dip* products (a different category from chips), and drops one outlier loyalty card that was clearly a bulk/commercial buyer rather than a household. |
| 2 | `02_merge_data.py` | both `*_clean.csv` files | `QVI_merged_data.csv` | Joins transactions to customers on loyalty card number and validates every transaction matched a customer (no nulls introduced, no row-count drift). |
| 3 | `03_visualizations.py` | `QVI_merged_data.csv` | 3 PNGs in `outputs/charts/` | Builds the segment overview heatmap, the daily sales trend line, and the target-segment brand/pack-size affinity chart. |
| 4 | `04_summary_tables.py` | `QVI_merged_data.csv` | 3 CSVs in `outputs/tables/` | Builds the numeric tables behind those charts, plus a Welch's t-test on unit price to back up the "Mainstream shoppers pay more" finding with a p-value. |

To reproduce everything from scratch: run the four scripts in order (each one reads what
the previous one wrote).

## Headline findings

*(the full reasoning and detail is in `reports/QVI_Chip_Category_Findings_Report.md`)*

- **Target segment:** Mainstream Young Singles/Couples and Mainstream Retirees stand out as
  the highest-value combination of segment size and spend.
- **Brand beats pack size:** which *brand* the target segment buys differs a lot from the
  rest of customers; pack size preference barely does — brand is the more useful lever for
  a category/promo strategy.
- **Seasonality:** sales build to a clear peak in the week before Christmas.
- **Price premium:** among Singles/Couples, Mainstream shoppers pay a statistically
  significant higher price per packet than Budget/Premium shoppers in the same life stage
  (see `price_premium_significance_test.csv` for the t-test).
